# 灰烬远征 · 废土十关（Unity / 团结引擎版）

2D 横版打怪闯关 DEMO。10 关、双 Boss、3 职业、45 套装备、伤势—体力联动、商店与存档。
**UI、角色、敌人、Boss、图标全部为 AI 生成美术**，无占位色块。

本版已从网页试玩版移植全部功能：**可走动的营地独立地图**、**开发者模式**、正确的角色/敌人朝向。

## 零、最快玩法：双击 exe 直接玩（推荐）

**不用打开 Unity 编辑器，不用点 Play，双击即可运行：**

```
<工程根目录>/灰烬远征/灰烬远征.exe
```

- 本仓库只包含 Unity 工程源码，**不含已构建的 exe**；exe 需在编辑器中按 `BuildWindows.Run()` 自行构建，产物默认输出到工程根目录同级的 `灰烬远征/` 文件夹。
- 这是构建好的 Windows 独立版（约 102 MB，含 `灰烬远征_Data` 等依赖文件）。
- **exe 必须和同目录的 `灰烬远征_Data`、`TuanjiePlayer.dll` 等文件待在一起**，不要单独把 exe 拷走。
- 无需 Unity 授权，可永久运行；**首次启动默认无边框全屏**（跟随桌面分辨率），可在设置里随时切换。
- 存档位置：`C:\Users\<用户名>\AppData\LocalLow\Ashfall Studio\灰烬远征\saves\`。
- 若移动整个文件夹到别处，双击新位置的 exe 同样能玩。

> `Tuanjie.exe -batchmode -quit -projectPath <工程路径> -executeMethod BuildWindows.Run`，
> 产物仍生成在上面的目录。

## 一、引擎版本与授权

工程使用 **团结引擎（Unity 中国版）2022.3.62t18**，版本记录在 `ProjectSettings/ProjectVersion.txt`。
用 Unity Hub 安装对应版本的团结引擎后打开即可。

> 团结引擎需要个人账号登录授权（Unity Personal 免费）；首次启动编辑器时按提示登录激活。

## 二、打开与试玩

1. Unity Hub → **添加** → 选择本仓库根目录（包含 `Assets/`、`ProjectSettings/`）→ 打开项目。
2. 首次导入等待资源处理完成（38 张 PNG + JSON）。
3. 打开场景 `Assets/Scenes/Game.unity`（已加入 Build Settings）。
4. 按 **Play**。无需手工拖组件：`GameBootstrap` 通过 `RuntimeInitializeOnLoadMethod` 自动创建游戏。
5. 主菜单选职业 → 开始新游戏；或读取 3 个手动存档槽位。

## 四、显示设置（全屏 / 无边框 / 窗口化 / 分辨率 / 界面大小）

主菜单点「设置」，或游戏中点 HUD 右上角「设置」，即可打开设置面板。上半部分是显示设置，修改后立即生效并自动保存：

| 项目 | 选项 | 说明 |
|---|---|---|
| 窗口模式 | 全屏 / 无边框 / 窗口化 | 全屏为独占显示；无边框占满屏幕但可快速切出（默认）；窗口化使用下方分辨率 |
| 分辨率 | 1280×720 / 1366×768 / 1600×900 / 1920×1080 / 2560×1440 + 当前桌面分辨率 | 窗口化下直接改变窗口大小；全屏/无边框下改变显示模式 |
| 界面大小 | 90% / 100% / 110% / 120% / 135% / 150% | 只缩放 UGUI（文字/按钮/HUD），**不改变角色、敌人与场景模型比例** |

「恢复默认」回到首次启动配置（无边框 + 桌面分辨率 + UI 100%）；「重新应用」在切换显示器或 Alt+Tab 异常后手动刷新。游戏中打开设置会暂停战斗，关闭后恢复；设置面板打开时按 Esc 先关闭设置（与其他面板共用同一个退出键）。

> **分辨率 / 界面大小不需要新建任何建模。** 分辨率只调用 `Screen.SetResolution()` 改变渲染输出；界面大小只改 `CanvasScaler.referenceResolution` 做 UI 等比缩放；角色、敌人、Boss、营地站点和背景图全部复用原有精灵/模型。

**金币只改显示与扣费判断，不改实际金币数值**——关闭后立即恢复正常经济，存档不会被污染。

## 六、已实现机制

- **伤势联动**：`体力上限 = 基础 × (0.5 + 0.5 × 血量比例)`，`回复 = 基础 × (0.4 + 0.6 × 血量比例)`，HUD 实时显示伤势等级与体力倍率。
- **唯一回血途径**：商店 5 档医疗消耗品（绷带 5 金/15HP → 药剂 100 金/回满），装备与套装不提供回血。
- **10 关**：第 5 关小 Boss「石甲守卫」、第 10 关大 Boss「深渊领主」；8 类敌人数据。
- **45 套装备**：每职业 15 套（灰 1 / 绿 2 / 蓝 3 / 紫 4 / 橙 5），四件同套激活、混搭无效。
- **掉落**：普通怪 30% / 精英 60% / Boss 100%，品质权重随关卡递进（高关卡紫橙为主），Boss 保底。
- **金币**：击杀金币随关卡放大（×1.0→×3.4），另有随关卡提升的通关奖励；商店刷新固定 5 金，不随关卡/次数涨价。
